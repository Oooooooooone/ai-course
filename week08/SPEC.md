# 주차 요금 계산기 스펙

## 1. 기술과 파일 구성
### 기술
- Python 3.10 이상, Flet 1.0. 다른 패키지는 쓰지 않는다. 파이썬에 들어 있는 모듈(random, json 등)은 쓸 수 있다.
- main.py는 과제 뼈대를 그대로 가져와 넓혀서 만든다. logic.py는 뼈대 없이 처음부터 만든다.
- 뼈대에 나온 Flet 문법만 쓴다. 뼈대에 없는 Flet 클래스, 인자, 속성은 쓰지 않는다. 기억하고 있는 Flet 문법은 옛 버전의 것이므로 쓰지 않는다.
- 다음은 Flet 1.0에 없으므로 쓰지 않는다: `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `Button(text=...)`, `page.window_width`, `ft.UserControl`, `TextField(error_text=...)`

### 파일 구성
| 파일 | 내용 |
| --- | --- |
| SPEC.md | 스펙 |
| logic.py | 계산과 판정. Flet을 import하지 않는다. 입력을 받아 결과를 돌려주는 함수만 있다 |
| main.py | 화면. 뼈대를 넓힌 것. 계산은 전부 logic.py의 함수를 불러서 한다 |
| test_logic.py | logic.py의 함수를 검사한다. 실행하면 통과와 실패 수를 출력한다 |

## 2. 동작 규칙
- 입차/출차 시각은 `HH:MM` (24시간제) 형식을 사용하며, 입력 시 앞뒤 공백은 자동으로 제거(strip)한다.
- 입력값이 비어있으면 "입차 시각을 입력하세요" 또는 "출차 시각을 입력하세요"를 안내한다. (둘 다 비면 입차 안내 우선)
- 시각 형식이 `HH:MM`이 아니면(예: 9:30, 0930, 09:3) "시각은 09:30처럼 입력하세요"를 안내한다.
- 시(00~23) 또는 분(00~59) 범위를 벗어나면 "없는 시각입니다"를 안내한다. (24:00 포함)
- 출차 시각이 입차 시각과 같거나 앞서면 "출차는 입차보다 뒤여야 합니다"를 안내한다.
- 계산에 성공하면:
  - 계산된 내역을 목록의 **맨 아래**에 한 줄 추가한다.
  - 전체 목록의 요금을 합산하여 "오늘 합계"를 실시간으로 갱신한다.
- 잘못된 입력 시 기존 목록과 합계는 유지하며, 빨간색 안내 문구만 표시한다.
- 목록의 [삭제] 버튼을 누르면 해당 항목이 즉시 제거되고 합계가 실시간으로 재계산된다.
- 모든 금액은 천 단위마다 쉼표(`,`)를 표시한다.

## 3. 화면
- **창 설정**: 
  - 제목: `주차 요금 계산기`
  - 크기: `480x600` (크기 조절 불가)
- **요소 구성 (위에서 아래 순서)**:
  1. **입력 영역**:
     - [입차 시각 (`TextField`, 라벨: `입차 시각 (HH:MM)`)] [출차 시각 (`TextField`, 라벨: `출차 시각 (HH:MM)`)] (한 줄 배치)
     - 계산 버튼 (`Button`, 글자: `계산하기`, 너비: 가로 꽉 차게)
  2. **안내 영역**:
     - 오류/안내 문구 표시 (`Text`, 빨간색)
  3. **목록 영역**:
     - 계산 결과 목록 (항목 형식: `09:30 → 11:05 | 95분 | 3,500원 [삭제]`)
  4. **합계 영역**:
     - 오늘 합계 표시 (`Text`, 초기값: `오늘 합계: 0원`)

## 4. 테스트

### 계산 함수 정의

#### 1) 시각 검증 함수
- `validate_time(time_str: str) -> (bool, str | None)`
  - `time_str`의 공백을 제거하고 형식이 `HH:MM`인지, 시/분이 범위 내에 있는지 검사한다.

#### 2) 요금 계산 함수
- `calculate_fee(minutes: int) -> int`
  - 주어진 주차 시간(분)을 바탕으로 요금을 계산한다. (최대 20,000원)

#### 3) 금액 포맷 함수
- `format_currency(amount: int) -> str`
  - 숫자를 천 단위 콤마가 포함된 문자열로 변환한다.

#### 4) 합계 계산 함수
- `calculate_total(fee_list: list[int]) -> int`
  - 요금 리스트를 받아 총합을 반환한다.

#### 5) 통합 계산 함수 (Main Logic)
- `process_calculation(start_input: str, end_input: str) -> (dict | None, str | None)`
  - 두 시각을 검증하고 요금을 계산하여 결과 딕셔너리를 반환한다.

### 테스트 케이스

#### [시각 검증 테스트 (validate_time)]
| 입력값 | 기대 결과 | 비고 |
| :--- | :--- | :--- |
| `""` | `(False, "시각은 09:30처럼 입력하세요")` | 빈 문자열 |
| `" 09:30 "` | `(True, None)` | 공백 포함 |
| `"9:30"` | `(False, "시각은 09:30처럼 입력하세요")` | 형식 오류 |
| `"0930"` | `(False, "시각은 09:30처럼 입력하세요")` | 형식 오류 |
| `"09:3"` | `(False, "시각은 09:30처럼 입력하세요")` | 형식 오류 |
| `"24:00"` | `(False, "없는 시각입니다")` | 범위 밖 |
| `"12:60"` | `(False, "없는 시각입니다")` | 범위 밖 |

#### [통합 계산 테스트 (process_calculation)]
| 입차 입력 | 출차 입력 | 기대 결과 | 비고 |
| :--- | :--- | :--- | :--- |
| `""` | `"10:00"` | `(None, "입차 시각을 입력하세요")` | 입차 빈칸 |
| `"10:00"` | `""` | `(None, "출차 시각을 입력하세요")` | 출차 빈칸 |
| `""` | `""` | `(None, "입차 시각을 입력하세요")` | 둘 다 빈칸 |
| `"9:30"` | `"10:00"` | `(None, "시각은 09:30처럼 입력하세요")` | 입차 형식 오류 |
| `"10:00"` | `"10:3"` | `(None, "시각은 09:30처럼 입력하세요")` | 출차 형식 오류 |
| `"10:00"` | `"25:00"` | `(None, "없는 시각입니다")` | 출차 범위 밖 |
| `"10:00"` | `"10:00"` | `(None, "출차는 입차보다 뒤여야 합니다")` | 같은 시각 |
| `"11:00"` | `"10:00"` | `(None, "출차는 입차보다 뒤여야 합니다")` | 출차가 앞섬 |
| `"09:00"` | `"09:30"` | `({'start': '09:00', 'end': '09:30', 'duration': 30, 'fee': 0}, None)` | 정상 (무료) |
| `"09:00"` | `"10:00"` | `({'start': '09:00', 'end': '10:00', 'duration': 60, 'fee': 1500}, None)` | 정상 (과금) |
| `"09:00"` | `"16:01"` | `({'start': '09:00', 'end': '16:01', 'duration': 421, 'fee': 20000}, None)` | 정상 (최대) |
