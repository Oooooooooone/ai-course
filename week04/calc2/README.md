# 계산기 (calc2)

## 설치

```
python -m pip install "flet[all]"
```

## 실행

```
python main.py
```

## 테스트

```
python test_calc.py
```

모든 테스트를 통과하면 `모든 테스트 통과 (20개)`가 출력됩니다.

## 파일 구성

- `calc.py` : 계산 로직 (`Calculator` 클래스)
- `main.py` : 화면 (Flet)
- `test_calc.py` : `calc.py` 단독 테스트
- `SPEC.md` : 스펙 문서
