# Todo 앱 프로젝트 스펙 (SPEC.md)

## 1. 개요
사용자가 할 일을 등록하고, 완료 상태를 변경하며, 삭제할 수 있는 단순한 웹 애플리케이션입니다. 모든 사용자가 공유하는 하나의 할 일 목록을 관리합니다.

## 2. 기술
- **Backend**: Python, Flask
- **Database**: SQLite
- **Frontend**: HTML, CSS (Vanilla CSS)

## 3. 파일 구성
- `app.py`: Flask 애플리케이션 메인 로직 및 라우트 정의
- `database.db`: SQLite 데이터베이스 파일 (앱이 처음 실행될 때 자동으로 생성됨)
- `static/css/style.css`: 애플리케이션 스타일 시트
- `templates/index.html`: 할 일 목록 및 입력 폼이 포함된 메인 페이지
- `test_app.py`: Flask의 test_client를 이용한 기능 테스트 스크립트 (python test_app.py로 실행)
- `README.md`: 프로젝트 설명 및 실행 방법 안내

## 4. 동작 규칙

| 라우트 | 메서드 | 입력 (Input) | 결과 (Output) |
| :--- | :--- | :--- | :--- |
| `/` | `GET` | 없음 | 전체 할 일 목록(최신순) 및 입력 폼 출력 |
| `/add` | `POST` | `title` (문자열) | 제목은 앞뒤 공백을 뗀 뒤 1자 이상 100자 이하여야 한다. 조건 미충족 시 추가하지 않고 오류 메시지와 함께 목록 페이지를 200으로 보여준다. 성공 시 `/`로 리다이렉트. |
| `/toggle/<int:todo_id>` | `POST` | `todo_id` (경로 변수) | 해당 ID의 완료 여부 반전, 성공 시 `/`로 리다이렉트 (없으면 404) |
| `/delete/<int:todo_id>` | `POST` | `todo_id` (경로 변수) | 해당 ID의 항목 삭제, 성공 시 `/`로 리다이렉트 (없으면 404) |

## 5. 화면
- **메인 화면**:
    - 상단에 할 일을 입력할 수 있는 입력창(Input)과 추가 버튼이 위치함.
    - 중앙에는 할 일 목록이 나열됨. 각 항목은 '제목', '생성 시각', '완료/미완료 체크 버튼', '삭제 버튼'을 포함함.
    - 할 일은 최신 생성된 항목이 가장 위로 오도록 정렬됨.
    - 완료된 항목은 취소선으로 표시한다.

## 6. 테스트
python test_app.py를 실행하면 전부 통과할 때 '모든 테스트 통과 (N개)'를 출력하고, 틀리면 요청과 기대값, 실제값을 출력한다.
테스트는 임시 DB 파일을 쓰고 실제 database.db는 건드리지 않는다.

| 요청 | 기대하는 결과 |
| :--- | :--- |
| `GET /` | 200 OK, 할 일 목록과 입력 폼이 정상적으로 보임 |
| `POST /add` (유효한 제목) | 302 Redirect, `/`로 이동, 목록에 추가됨 |
| `POST /add` (정확히 100자) | 302 Redirect, `/`로 이동, 목록에 추가됨 |
| `POST /add` (빈 문자열) | 200 OK, 오류 메시지 표시 및 데이터 추가 안 됨 |
| `POST /add` (공백만 포함) | 200 OK, 오류 메시지 표시 및 데이터 추가 안 됨 |
| `POST /add` (100자 초과) | 200 OK, 오류 메시지 표시 및 데이터 추가 안 됨 |
| `POST /add` ("A"), `POST /add` ("B") 후 `GET /` | 200 OK, "B"가 "A"보다 먼저 나옴 |
| `POST /toggle/<존재하는_ID>` | 302 Redirect, `/`로 이동, 해당 항목의 완료 여부가 반전됨 |
| `POST /toggle/<없는_ID>` | 404 Not Found |
| `POST /delete/<존재하는_ID>` | 302 Redirect, `/`로 이동, 해당 항목이 목록에서 사라짐 |
| `POST /delete/<없는_ID>` | 404 Not Found |
| `GET /static/css/style.css` | 200 OK, CSS 파일이 정상적으로 로드됨 |

## 7. 완료 전 점검
- [ ] 제목 입력 시 100자 제한 및 공백 체크 로직이 작동하는가?
- [ ] 할 일 목록이 최신순(내림차순)으로 정렬되는가?
- [ ] 존재하지 않는 ID를 삭제/토글할 때 404 에러를 반환하는가?
- [ ] 외부 CSS/JS 프레임워크 없이 HTML과 CSS만 썼는가?
- [ ] SQLite에 데이터가 정확히 저장되고 불러와지는가?
- [ ] python test_app.py가 모든 테스트 통과를 출력하는가?

## 8. 하지 않는 것
- 사용자 인증 (로그인, 회원가입, 로그아웃)
- 할 일 내용 수정 기능
- 외부 CSS 프레임워크 사용 (Bootstrap 등)
- 자바스크립트 프레임워크 사용 (React, Vue 등)
- 정렬 및 필터링 기능 (최신순 고정)
- 마감 기한 설정 기능
