전화번호를 어떤 형식으로 정리하고 싶으신가요? 보통 가장 많이 쓰이는 세 가지 패턴(**하이픈 제거, 하이픈 추가, 특정 형식 통일**)에 맞춰 파이썬(Python) 함수를 만들어 보았습니다.

### 1. 파이썬 코드 예시

```python
import re

def format_phone_number(phone, mode='hyphen'):
    """
    전화번호를 정리하는 함수
    :param phone: 입력된 전화번호 (문자열)
    :param mode: 'hyphen' (010-1234-5678), 'clean' (01012345678), 'space' (010 1234 5678)
    :return: 정리된 전화번호 문자열
    """
    # 1. 숫자만 남기기 (특수문자, 공백 제거)
    digits = re.sub(r'\D', '', phone)
    
    # 숫자가 너무 적으면 그대로 반환
    if len(digits) < 9:
        return phone

    if mode == 'clean':
        # 숫자만 붙여서 반환
        return digits

    elif mode == 'space':
        # 010 1234 5678 형식 (공백 사용)
        if len(digits) == 11:
            return f"{digits[:3]} {digits[3:7]} {digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]} {digits[3:6]} {digits[6:]}"
        return digits

    elif mode == 'hyphen':
        # 010-1234-5678 형식 (하이픈 사용)
        if len(digits) == 11:
            return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
        elif len(digits) == 10:
            return f"{digits[:3]}-{digits[3:6]}-{digits[6:]}"
        return digits

    else:
        return phone

# --- 테스트 코드 ---
test_numbers = [
    "01012345678",          # 숫자만 있는 경우
    "010-1234-5678",        # 이미 하이픈이 있는 경우
    "010.1234.5678",        # 점이 찍힌 경우
    "02 123 4567",          # 지역번호(10자리)인 경우
    "010 1234 5678",        # 공백이 있는 경우
    "(010) 1234-5678"       # 괄호가 있는 경우
]

print(f"{'원본':<15} | {'하이픈형':<15} | {'숫자만':<15}")
print("-" * 50)
for num in test_numbers:
    hyphen = format_phone_number(num, 'hyphen')
    clean = format_phone_number(num, 'clean')
    print(f"{num:<15} | {hyphen:<15} | {clean:<15}")
```

### 2. 코드 설명

1.  **`re.sub(r'\D', '', phone)`**: 정규표현식을 사용하여 숫자가 아닌 모든 문자(`\D`)를 빈 문자열로 바꿉니다. 즉, 하이픈, 공백, 괄호 등을 한 번에 다 지우고 **순수 숫자만 추출**합니다.
2.  **조건부 포맷팅**:
    *   **11자리 (010-1234-5678)**: 휴대폰 번호 형식에 맞춰 슬라이싱합니다.
    *   **10자리 (02-123-4567)**: 일반 전화나 지역 번호 형식에 맞춰 슬라이싱합니다.
3.  **모드 설정 (`mode`)**:
    *   `hyphen`: 우리가 흔히 보는 `010-0000-0000` 형태입니다.
    *   `clean`: 데이터베이스 저장용으로 좋은 `01000000000` 형태입니다.
    *   `space`: 가독성을 위해 공백을 넣은 형태입니다.
