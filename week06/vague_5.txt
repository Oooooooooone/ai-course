전화번호를 어떤 형식으로 정리하고 싶은지에 따라 여러 가지 방법이 있습니다. 가장 대표적인 세 가지 상황(하이픈 제거, 하이픈 추가, 특정 형식으로 통일)에 맞춰 파이썬(Python) 함수를 만들어 보았습니다.

### 1. 숫자만 남기기 (하이픈 등 모든 특수문자 제거)
데이터 분석이나 DB 저장용으로 가장 많이 쓰이는 방식입니다.

```python
import re

def clean_phone_number(phone):
    # 숫자가 아닌 모든 문자를 제거합니다.
    return re.sub(r'[^0-9]', '', str(phone))

# 테스트
print(clean_phone_number("010-1234-5678"))  # 출력: 01012345678
print(clean_phone_number("02.123.4567"))    # 출력: 021234567
print(clean_phone_number("(010) 1234 5678")) # 출력: 01012345678
```

### 2. 표준 하이픈 형식으로 만들기 (`010-1234-5678`)
지저분한 번호들을 보기 좋게 `00-0000-0000` 형식으로 통일합니다.

```python
import re

def format_phone_number(phone):
    # 1. 일단 숫자만 추출합니다.
    digits = re.sub(r'[^0-9]', '', str(phone))
    
    # 2. 길이에 따라 형식을 지정합니다.
    length = len(digits)
    
    if length == 8: # 지역번호가 있는 경우 (예: 021234567)
        # 이 부분은 지역번호 길이에 따라 복잡해질 수 있어 예시로만 작성합니다.
        return f"{digits[:2]}-{digits[2:6]}-{digits[6:]}" 
    
    elif length == 10: # 02-123-4567 또는 010-123-4567
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    
    elif length == 11: # 010-1234-5678
        return f"{digits[:3]}-{digits[3:7]}-{digits[7:]}"
    
    else:
        return digits # 형식이 맞지 않으면 숫자만 반환

# 테스트
print(format_phone_number("01012345678"))     # 출력: 010-1234-5678
print(format_phone_number("021234567"))      # 출력: 02-1234-567
print(format_phone_number("010-1234-5678"))   # 출력: 010-1234-5678
```

### 3. [종합판] 실무에서 바로 쓰는 함수
입력값이 무엇이든 **숫자만 뽑아낸 뒤, 한국 전화번호 표준 규격에 맞춰** 하이픈을 넣어주는 완성형 함수입니다.

```python
import re

def standardize_phone(phone):
    # 1. 숫자만 남기기
    num = re.sub(r'[^0-9]', '', str(phone))
    
    # 2. 패턴 매칭을 통한 하이픈 삽입
    # 휴대폰 (010-xxxx-xxxx)
    if re.match(r'^010\d{8}$', num):
        return f"{num[:3]}-{num[3:7]}-{num[7:]}"
    
    # 일반 전화 (지역번호 포함)
    # 서울(02)은 2자리, 그 외 지역은 3자리인 점을 고려
    if num.startswith('02'):
        if len(num) == 9: # 02-xxx-xxxx
            return f"{num[:2]}-{num[2:5]}-{num[5:]}"
        elif len(num) == 10: # 02-xxxx-xxxx
            return f"{num[:2]}-{num[2:6]}-{num[6:]}"
    elif len(num) >= 9 and len(num) <= 11:
        # 그 외 지역번호 3자리 (031, 051 등)
        if len(num) == 10: # 031-xxx-xxxx
            return f"{num[:3]}-{num[3:6]}-{num[6:]}"
        elif len(num) == 11: # 031-xxxx-xxxx
            return f"{num[:3]}-{num[3:7]}-{num[7:]}"
            
    return num # 규칙에 맞지 않으면 숫자만 반환

# 테스트 케이스
test_list = [
    "01012345678",
    "010-1234-5678",
    "(02)1234567",
    "02.123.4567",
    "031-123-4567",
    "0511234567"
]

for t in test_list:
    print(f"{t}  =>  {standardize_phone(t)}")
```

### 활용 팁:
*   **Pandas 사용 시:** 만약 엑셀 파일 같은 대량의 데이터를 정리한다면 `df['전화번호'].apply(standardize_phone)`와 같이 사용하여 한 번에 처리할 수 있습니다.
*   **정규표현식(`re`):** 전화번호는 형식이 매우 다양하기 때문에 `re` 모듈을 사용하는 것이 가장 빠르고 정확합니다.
